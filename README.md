# Blocktrace: Agent Protocol

A dependency-free first-person browser prototype set inside a hostile blockchain network.

## Play

Open `index.html` in a static web server. No build step or package manager is required.

## Core loop

1. Enter the network.
2. Explore the protocol map in first person.
3. Recover three encrypted shards.
4. Use the Agent beacon to resync the route.
5. Open the Genesis Vault.

## Autonomous development loop

The intended coding-agent workflow is:

**Inspect → Plan → Implement → Test → Fix → Improve**

The agent should keep the game playable after every change, prefer small commits, avoid unnecessary dependencies, and add tests or browser checks when practical.
